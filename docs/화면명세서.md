# 커맨드웨어 등록 앱 화면 명세서

- 대상: 안드로이드 폰(세로), 보조자(보호자·치료사)가 사용
- 기준: `Main.dc.html` 목업(데스크톱 2단 배치)을 폰 한 화면에 맞게 다시 배치
- 상태: ✅ 구현됨 · 🔧 이번에 개선 · 📝 제안(아직 구현 안 함)

---

## 1. 편의성 원칙

목업은 1440px 가로 화면이라 모형과 설정을 나란히 놓았다. 폰에서 이것을 세로로 쌓기만 하면, 한 작업에 필요한 것들이 스크롤 위아래로 흩어진다. 아래 원칙으로 화면마다 무엇을 고정하고 무엇을 접을지 정한다.

| # | 원칙 | 이유 |
|---|---|---|
| P1 | **한 작업의 출발점과 도착점은 한 화면에** 둔다 | 끌어다 놓기·비교·판정은 둘 다 보여야 할 수 있다. 예) 미배치 노드 ↔ 신체 모형 |
| P2 | **작업대는 고정, 설정은 아래 시트로** 접는다 | 자주 하는 조작(배치·녹화·테스트)은 스크롤 없이, 가끔 바꾸는 값(보정·지연 시간)은 필요할 때만 펼친다 |
| P3 | **보조자는 폰이 아니라 사용자를 본다** | 녹화·테스트 중에는 화면을 보지 않아도 되게 소리·진동·큰 글씨로 알린다 |
| P4 | **엄지가 닿는 아래쪽에 주요 버튼** | 한 손으로 폰을 들고 다른 손으로 사용자를 부축하는 상황 |
| P5 | **실수는 되돌릴 수 있게** | 삭제·배치 해제·버리기는 확인 창 대신 "되돌리기"가 있는 알림으로 빠르게 |
| P6 | **지금 어디까지 했는지 늘 보이게** | 처음 쓰는 보조자도 다음에 할 일을 알 수 있게 |

## 2. 공통 요소

| 요소 | 내용 | 상태 |
|---|---|---|
| 헤더 | 한 줄: `커맨드웨어` + 허브 연결 칩 + 시뮬레이션 칩 | 🔧 두 줄 → 한 줄로 줄여 작업 화면 높이 확보 |
| 하단 탭 | A 노드 · B 녹화 · C 목록 · D 테스트 · E 출력 | ✅ |
| 안내 띠 | 동작 결과 알림("노드 04를 왼 윗팔에 붙였습니다") | ✅ 📝 4초 뒤 자동으로 사라지고, 되돌릴 수 있는 일이면 **되돌리기** 버튼(스낵바) |
| 진행 체크 | 노드 배치 → 기준 자세 → 동작 1개 이상 → 허브 반영 | 📝 헤더 아래 얇은 4칸 표시, 누르면 해당 탭으로 이동 (P6) |
| 연결 끊김 | 허브·노드 연결이 끊기면 모든 화면 위에 빨간 띠 | 📝 실물 BLE 연결 단계에서 |
| 상태 저장 | 노드 배치·보정값·기준 자세 | 📝 지금은 앱을 다시 켜면 처음으로 돌아감 → SQLite 또는 SharedPreferences에 저장 |

## 3. 화면별 명세

### A. 노드 설정·보정

**목적**: 실물 노드를 몸에 붙인 위치를 모형에 똑같이 표시하고, 기준 자세와 체형 보정을 맞춘다.

**한 화면 고정 (작업대)** 🔧
- 신체 모형(남는 높이를 모두 사용), 앞/뒤 보기, 배치 수 `배치 3/4`
- 바로 아래 **미배치 노드 줄**(가로 스크롤) + `노드 추가`
- → 미배치 노드를 길게 눌러 모형으로 끌기, 모형의 노드를 줄로 끌어 해제 (P1)

**아래 시트** 🔧
- 접힘: `선택한 부위 · 왼 아래팔 · 노드 04 · 배터리 96% · 연결 불량`
- 펼침: 노드 정보 4칸, LED 깜빡이기, 배치 해제 / 개인 보정 슬라이더 3개 / 노드 흔들기 / 기준 자세 측정

**제안** 📝
- 노드를 끌기 시작하면 시트를 자동으로 접고, 놓을 수 있는 부위를 옅게 강조
- 실물 노드를 흔들면 모형의 점뿐 아니라 **미배치 줄의 칩도 같이 깜빡임**
- 배터리 20% 미만·연결 불량 노드가 있으면 헤더 칩을 주황색으로 바꿔 어느 탭에서든 보이게
- 기준 자세 측정은 3초 카운트다운을 **소리**로도 알림 (P3)

---

### B. 동작 녹화·검토

**목적**: 사용자가 같은 동작을 3~10번 하는 동안 녹화하고, 이상한 기록을 골라낸다.

**이전 문제**: 모형, 녹화 설정 6가지, 녹화 버튼, 기록 목록이 모두 세로로 쌓여서 녹화 버튼을 누르려면 스크롤해야 하고, 녹화 중 모형이 화면 밖에 있었다.

**한 화면 고정 (작업대)** ✅
- 신체 모형(녹화 중 움직임 표시, 쓰지 않는 노드는 흐리게), 카운트다운 원
- 설정 요약 한 줄: `오른팔 들기 · 포즈형 · 노드 02·03 · 지연 3초 · 1초` → 누르면 시트 펼침
- 진행 막대 `남긴 기록 3개 · 최소 3 · 권장 10`, 경고 기록이 있으면 `⚠ 결정 필요 1개 ›` (누르면 시트를 열고 그 기록으로 스크롤)
- 화면 아래 **큰 녹화 버튼**(엄지 위치, P4): `4번째 녹화 시작` / `3초 후 시작` / `녹화 중` + 옆에 `허브에 넣기`

**아래 시트** ✅ (처음엔 숨김, 녹화를 시작하면 자동으로 닫힘)
- 기록 목록(다시 보기 / 남기기 / 버리기) — 다시 보기를 누르면 시트를 닫고 모형으로 재생
- 저장 버튼 `폰에 저장` · `허브에 넣기`
- 녹화 설정(이름, 트리거 방식, 사용 노드, 시작 지연, 녹화 길이, 일치 기준)

**구현한 편의 기능** ✅
- **사용 노드는 모형에서 바로 고르기**: 모형의 노드를 누르면 켜고 끔 (P1)
- 카운트다운·녹화 시작·끝을 **삐 소리 + 진동**으로 알림, 경고 기록은 다른 소리 (P3) — 기준 자세 측정에도 적용

**남은 제안** 📝
- **연속 녹화**: 한 번 누르면 "지연 → 녹화 → 2초 쉼"을 정한 횟수만큼 반복 (보조자가 매번 폰을 누르지 않게)
- **볼륨 키로 녹화 시작**: 화면을 보지 않고도 시작 (P3, P4)
- 저장하면 C로 바로 넘어가는 대신 `저장했습니다 · 테스트해 보기 →` 선택지

---

### C. 동작 목록

**목적**: 폰에 저장한 동작 중 3개를 골라 허브 슬롯에 넣고, 허브에 반영한다.

**한 화면 고정** 📝
- 위: **허브 슬롯 3칸을 작게 가로로** (이름 + 유형 배지만) + 동기화 상태 `반영 안 됨 · 지금 보내기`
- 아래: 폰에 저장된 동작 목록(리스트뷰)
- → 목록의 동작을 길게 눌러 **슬롯 칸으로 끌어 넣기/교체** (P1). 지금의 "허브에 넣기 → 슬롯 고르기" 2단계를 한 동작으로

**제안** 📝
- 슬롯을 누르면 그 동작의 상세(녹화 추가·테스트·출력 연결·빼기)를 시트로
- 목록에서 **옆으로 밀어 삭제 + 되돌리기** (P5), 지금의 확인 창 대신
- 기준 자세가 다른 동작은 목록에서 흐리게 하고 `현재 기준(선 자세)과 다름` 배지
- 허브 반영이 안 된 상태로 D 탭에 가면 `허브에 아직 반영 안 됨` 안내

---

### D. 실시간 테스트

**목적**: 허브에 넣은 동작이 의도대로 발동하는지, 평소 움직임에 잘못 발동하지 않는지 확인한다.

**문제(현재)**: 흉내 버튼 → 모형 → 판정 막대 → 발동 기록 순서로 쌓여 있어서, 버튼을 누르면 판정 막대가 화면 밖이다.

**한 화면 고정** 📝
- 위: 흉내 버튼 한 줄(가로 스크롤) — 실물 연결 후에는 "실제 센서" 표시로 바뀜
- 가운데: **모형(작게, 왼쪽) + 슬롯 3개 판정 막대(오른쪽)** 나란히
- 발동 순간: 모형 위 배너 + **진동** + (출력 실제 보내기 켜짐이면) 소리 (P3)

**아래 시트** 📝
- 슬롯별 인식 민감도 슬라이더
- 발동 기록(최근 8개), `출력 실제 보내기` 스위치

**제안** 📝
- 판정 막대를 누르면 그 슬롯 민감도 슬라이더가 바로 열림
- **오발동 표시**: 발동 기록에서 "이건 잘못 발동" 표시 → 민감도 올리기 제안
- 평소 움직임 1분 테스트 버튼: 1분 동안 발동 횟수를 세서 `오발동 0회 ✓` 결과 표시

---

### E. 출력 연결 (다음 단계)

**목적**: 동작마다 어떤 수신 모듈·포트로 신호를 보낼지 정한다.

**한 화면** 📝
- 왼쪽 열: 허브 슬롯 3개 / 오른쪽 열: 출력(소리 트랙 1~3, 모터, LED, 키 입력)
- 슬롯과 출력을 **선으로 연결**(누르고 누르기) — 지금은 "슬롯 번호 = 트랙 번호" 고정
- 출력마다 `테스트 신호` 버튼으로 바로 확인
